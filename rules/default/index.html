    Default¶

    Every rule, as its default file defines it for every model. A provider's or model's files change some of them; the last column names those, and their pages show each model's view. Without -m, validia lint reads only these.

    wording¶

    Released 2026-10-07; a pin reads it as wording = "1.0.0" under [lint.rules].

    Rule Finds Reads Severity Changed by provider or model
    wording/capitals Emphasis in capitals prompt info anthropic/default: warn on 5 models; info on the rest
    google/default: warn on gemini-3*; info on the rest
    openai/default: warn on gpt-4.1*, gpt-5; info on the rest
    wording/capitals-in-tool Steering in capitals in a tool description tool descriptions warn —

    wording/expired-date A date-limited instruction prompt warn —
    wording/length-cap A hard length cap in the prompt prompt warn —
    wording/old-model-name Names an old model prompt warn —
    wording/unwrapped-input Untrusted input without delimiters prompt warn —
